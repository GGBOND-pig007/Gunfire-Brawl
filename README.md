## 简介

微信小游戏平台上的双人对战射击游戏。玩家操控角色在横版地图上移动、
瞄准射击，通过走位、技能与资源争夺击败对手。

本项目从零搭建，用于完整实践一条小游戏端到端链路：
**Unity 工程 → WebGL 构建 → 微信小游戏转换 → 真机运行 → 热更 → 联机对战**。

## 如何运行

**环境要求**：Unity 2022.3 LTS

1. 用 Unity Hub 打开本工程
2. 切换到 **WebGL** 平台
3. 使用 `Build Settings` 构建
4. 用 **微信开发者工具** 导入 WX-WASM-SDK-V2 转换产物
5. 真机预览 / 调试

### 获取微信小游戏转换插件

微信小游戏转换插件（`Assets/WX-WASM-SDK-V2/`）**未包含在本仓库中**。
该目录约 130 MB，且含 macOS / Linux 专用二进制文件，在 Windows 下无法使用，
因此通过 `.gitignore` 排除。

请从微信官方渠道获取后放入 `Assets/WX-WASM-SDK-V2/`，目录结构如下：

```
Gunfire-Brawl/
└── Assets/
    └── WX-WASM-SDK-V2/    # ← 自行放入
```
